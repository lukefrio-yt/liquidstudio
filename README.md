# Liquid Glass SDF Studio

> **A real-time WebGL2 raymarched SDF Liquid Glass shader studio with 16-bit float text/SVG etching, 6 3D shapes, keyframe animation, and 4K MP4 export.**

## English

### Overview
**Liquid Glass SDF Studio** is a browser-based, real-time **WebGL2 raymarching** and **Signed Distance Field (SDF)** studio focused on physically inspired **Liquid Glass** optics—featuring smooth refraction, chromatic dispersion, Fresnel reflections, and glossy specular highlights.

### Key Features
- **WebGL2 Raymarched SDF Shader:** Real-time raymarching pipeline with smooth SDF blending, refractive glass shading, dispersion, and dynamic lighting.
- **6 3D Shapes:** Switch between 6 procedural 3D SDF primitives/shapes to sculpt and compose glass forms.
- **Custom Text & SVG Etching:** Carve and etch custom text or vector SVG graphics directly onto/into the 3D glass surface using **16-bit float** distance textures for crisp, artifact-free edges.
- **Interactive Touch Waves:** Real-time ripple and wave deformations triggered by pointer/touch interaction across the liquid surface.
- **Keyframe Animation:** Built-in timeline with keyframe interpolation for animating shape transforms, shader parameters, and camera/scene motion.
- **Offline 4K MP4 Export:** Render and export deterministic, frame-accurate **4K MP4** videos directly from the browser without real-time frame drops.

### Getting Started
1. Open `index.html` in a modern WebGL2-capable browser (or via GitHub Pages).
2. Choose one of the 6 3D shapes, customize glass/lighting parameters, and optionally load custom text or an SVG.
3. Interact with the canvas to trigger touch waves, set animation keyframes, and export your scene as a 4K MP4.

## Čeština

### Přehled
**Liquid Glass SDF Studio** je webové studio běžící v reálném čase na **WebGL2 raymarchingu** a **Signed Distance Field (SDF)** geometrii. Zaměřuje se na realistickou optiku **tekutého skla (Liquid Glass)** – včetně lomu světla, chromatické disperze, Fresnelových odrazů a hladkých zrcadlových odlesků.

### Hlavní funkce
- **WebGL2 Raymarched SDF Shader:** Raymarchingový shader v reálném čase s plynulým prolínáním SDF tvarů, refrakcí skla, disperzí a dynamickým nasvícením.
- **6 3D tvarů:** Výběr ze 6 procedurálních 3D SDF tvarů pro modelování a kompozici skleněných objektů.
- **Vlastní text a SVG rytí:** Možnost vkládat vlastní text nebo vektorové SVG grafiky přímo do povrchu 3D skla s využitím **16-bit float** textur pro ostré a čisté hrany.
- **Dotykové vlny:** Interaktivní vlnění a deformace tekutého povrchu reagující v reálném čase na pohyb myši či dotyk.
- **Keyframy (klíčové snímky):** Vestavěná časová osa s interpolací klíčových snímků pro animaci tvarů, parametrů shaderu i pohybu scény.
- **Offline 4K MP4 export:** Deterministické snímkové vykreslování a export videí ve **4K MP4** přímo z prohlížeče bez ztráty snímků.

### Jak začít
1. Otevřete `index.html` v moderním prohlížeči s podporou WebGL2 (nebo přes GitHub Pages).
2. Vyberte jeden ze 6 3D tvarů, upravte parametry skla a světla, případně přidejte vlastní text nebo SVG.
3. Interakcí s plátnem vyvolejte dotykové vlny, nastavte klíčové snímky animace a výslednou scénu vyexportujte do 4K MP4.
